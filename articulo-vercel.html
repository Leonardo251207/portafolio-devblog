02 Asistente de despliegue

Guía Interactiva: El Flujo de Despliegue Paso a Paso

PASO_01

Prepara y publica tu repositorio

Confirma tus cambios y envía la rama principal a GitHub para que Vercel pueda importarla.

✓ REPOSITORIO_SINCRONIZADO
terminal — despliegue
git add . git commit -m "Preparar despliegue" git push origin main _

PASO_02

Conecta GitHub con Vercel

Selecciona el repositorio del portafolio y permite que Vercel detecte automáticamente el proyecto.

✓ PROYECTO_IMPORTADO
terminal — despliegue
vercel link Seleccionando: tu-portafolio Proyecto conectado correctamente _

PASO_03

Revisa la configuración de compilación

Define el comando de compilación y verifica que la carpeta de salida coincida con tu proyecto.

✓ CONFIGURACIÓN_VALIDADA
terminal — despliegue
Comando: pnpm build Directorio de salida: dist Entorno: producción _

PASO_04

Publica y comparte tu dominio

Inicia el despliegue final. Vercel generará una URL pública con HTTPS automáticamente.

✓ DOMINIO_ACTIVO
terminal — despliegue
vercel --prod Asignando dominio seguro... https://tu-portafolio.vercel.app _
